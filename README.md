# Interactive Quiz App

A simple, interactive quiz application built with HTML, CSS, and JavaScript.

## Features

- **User Name Input**: Personalizes the quiz experience.
- **Timed Questions**: 15 seconds per question.
- **Score Tracking**: Tracks and displays your score at the end.
- **Responsive Design**: Works on mobile and desktop.
- **Clean UI**: Modern and user-friendly interface.

## Live Demo

Check out the live version here: [Interactive Quiz](https://hemu-madu.github.io/Interactive-Quiz/)

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/hemu-madu/Interactive-Quiz.git
   ```

2. Open `index.html` in your browser.
